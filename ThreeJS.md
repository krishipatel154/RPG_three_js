## What is Scene?
Scene is the root of the object graph. It is used to hold all the objects, lights, and cameras that make up the 3D scene. It is also responsible for rendering the scene and managing the rendering loop.

## What is WebGL?
WebGL is a JavaScript API for rendering 3D graphics in a web browser. It is based on OpenGL ES, which is a subset of the OpenGL API used for embedded systems. WebGL allows developers to create interactive 3D graphics that can be rendered in real-time in a web browser without the need for plugins.

## What is mesh?
A 3D object is represented as a mesh, which is comprised of it "geometry" and "material". Geometry defines the shape of the object, while material defines how the object looks (color, texture, etc.). A mesh is created by combining geometry and material together.
